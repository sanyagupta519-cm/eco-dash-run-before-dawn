# 🎮 EcoDash – Run Before Dawn

## 📌 About the Project

EcoDash is an endless runner game developed using Unity.
The player navigates through a forest environment, avoids obstacles, and aims to survive as long as possible before dawn.

---

## 🚀 Features

* 🌲 Forest-themed environment
* 🏃 Endless running gameplay
* 🎯 Obstacle avoidance mechanics
* 🔫 Player controls and targeting system
* 🎵 Background sounds for immersive experience

---

## 🛠️ Built With

* Unity (Game Engine)
* C# (Scripting)

---

## 📂 Project Structure

* Assets → Contains all game assets (scripts, models, scenes, etc.)
* Packages → Unity package dependencies
* ProjectSettings → Unity project configuration

---

## ▶️ How to Run the Project

1. Download or clone this repository
2. Open Unity Hub
3. Click on **Open Project**
4. Select the project folder
5. Press **Play** in Unity Editor
